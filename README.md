# Buggy Boy (private copy)

A password-locked build of a fan remake of **Buggy Boy** for the Commodore 64, kept here so it can go on
a phone or tablet home screen.

The game itself is in `game.bin`, encrypted (AES-256-GCM, key from the password through PBKDF2). Without
the password nothing in this repository can be played or read. The password is only shared privately,
with people who own the original C64 game.

Buggy Boy is a 1985 Tatsumi arcade game; the Commodore 64 version was published by Elite Systems in 1987.
This is a free, non-commercial fan project, not affiliated with or endorsed by the rights holders.
